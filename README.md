# 🌍 Visão Cidadã - Plataforma ESG e Logística Preditiva

Plataforma desenvolvida durante o **Hackathon Visão Cidadã**, promovido pelo time **Enactus AGEAD UFMS**. O sistema atua como uma solução digital para o mapeamento de descarte irregular de resíduos e gestão de impacto ambiental (ESG).

## 🚀 Funcionalidades Principais

* **📍 Mapa Preditivo de Descarte:** Monitoramento em tempo real de focos de descarte irregular em Campo Grande (MS), com categorização de risco (Dengue, Entulho, etc).
* **🤖 Análise Inteligente com IA:** Integração com Inteligência Artificial para classificar os alertas enviados pela população e sugerir ações de mitigação.
* **📊 Dashboard ESG:** Painel dinâmico focado nas métricas das campanhas de "Drive-Thru" ecológico, calculando automaticamente:
  * Emissões de CO₂ evitadas.
  * Litros de água preservados.
  * Volume total de materiais reciclados.
* **♻️ Guia do Descarte:** Interface educativa ajudando a população a separar corretamente os resíduos (✔️ Recicláveis vs ❌ Rejeitos).

## 💻 Tecnologias Utilizadas

* **Back-end:** Python, Django
* **Front-end:** HTML5, CSS3, JavaScript
* **Inteligência Artificial:** Integração via API (Groq)
* **Banco de Dados:** SQLite3
